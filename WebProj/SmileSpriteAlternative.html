การศึกษาและความเชี่ยวชาญ

พัฒนาแอปพลิเคชัน HTML Canvas ด้วย JavaScript เพื่อสาธิตการใช้งานกราฟิก 2D รวมถึงใช้โครงสร้างข้อมูลสไปรต์ การแปลงทางเรขาคณิต และการจัดการเมาส์

สรุปโปรเจกต์

  • Interactive Computer Graphics: วาดภาพและแปลงสไปรต์บน Canvas พร้อมการควบคุมแบบไดนามิก
  • MyPaint: โปรแกรมวาดภาพพื้นฐานบน HTML Canvas สามารถใช้เครื่องมือวาดและลบได้
